# openapi-fs
- A little experiment attempting to learn FUSE.
- Takes an OpenAPI specification file and creates a filesystem representing the data.
- Maps filesystem commands like cat, rm, ls, sed to CRDUL methods over REST API using httpx
- Includes a little FastAPI server as a test case to show off the project at a high level.

- [GitHub](https://github.com/freyamade/openapi-fs)
